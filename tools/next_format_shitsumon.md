# 次のフォーマット案：【???】だけど質問ある？スレ（2027年〜の候補）

2chの定番「〇〇だけど質問ある？」で、スレタイの〇〇が伏せられている。>>1の正体は物・生き物など。住人の質問に>>1が答えるレスが1つずつ公開され、何レス目で正体を当てたかを競う（判定は自由入力＋キーワード、惜しい答えには住人がレス）。

- >>1の答えは「めちゃくちゃ難解」にする（ユーザー指示）。ウソは書かない。全部、正体を知ってから読むと「確かにそうだ」と言える事実だけで書く。
  - 序盤: 比喩と遠回しだけ。何にでも読める（例: 自販機「生まれてから一歩も動いたことがない。なのに毎日、知らない誰かに貢がれている」）
  - 中盤: 別の物に読めるミスリードを1つ入れる（例:「冬になると、半分だけ体温が上がる」→人間・動物にも読める）
  - 終盤: 正体を知っている人にだけわかる決定打（例:「つり銭切れの日は、口を閉じて黙る」）
- 正体を知ってから最初のレスを読み返すと全部つながる＝どんでん返しと同じ気持ちよさ
- 結果は「4レス目でわかった🟩⬜⬜⬜⬜⬜」で投稿
