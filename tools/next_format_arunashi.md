# 次のフォーマット案：あるなし掲示板（2027年〜の候補）

スレタイ「【あるなし】これどういう法則か教えて」。法則に当てはまるレスが1つずつ公開され、わかった時点で答える。何レス目で正解したかを競い、Xに「2レス目でわかった🟩⬜⬜⬜⬜」で投稿する。
例: きたにたつや／にしのかな／ひがしのけいご／みなみのたくみ → 方角が付く有名人

- 判定: 自由入力＋キーワード判定（ユーザー選択。4択は総当たりで正解できるのでNG）
  - 正解キーワードを複数用意（例: 方角／東西南北／北南東西）
  - 惜しい答えには住人がレスで返す（「北だけ？」「歌手は関係ないｗ」）＝かくれんぼスレの near と同じ
  - 1レスごとに回答は1回まで（当てずっぽうの連打を防ぐ）。何回外したかも結果に出す
  - 公開後、GAで外れた答えを集めてキーワードを足していく
- 仕掛け: 途中に「ない」のレスや、ほかの住人の外れ予想（ミスリード）を混ぜる。序盤は複数の法則に読めるように並べる
- 量産: 法則の型×単語リストで自動生成（動物が隠れている、回文、方角の付く有名人、頭を取ると別の言葉…）、最後に人の目で確認
